# RUCDAO 项目计划书

> **让每一次志愿服务都被看见、被记录、有回响**

> 配套材料：《01-乡建DAO调研报告》《02-可行性与合规分析》（深度资料，供进一步查阅）；可交互产品原型已上线试用

## 摘要（30 秒版）

**问题**：学生找志愿项目靠刷群、报名靠接龙、服务记录靠 Excel、时长证明等一个学期——信息不对称、记录不可信、激励缺位。

**方案**：搭建 **RUCDAO 校内志愿服务平台**——全校志愿项目一处发布、一处寻找；学生参与后，系统自动记录服务时长并发放"**米粒**"（志愿时数的电子凭证，1 小时 = 100 粒）；米粒可以换面包券、校园文创、参访机会；所有服务记录同步录入"志愿北京"。

**创新**：借鉴**乡建DAO**（温铁军教授团队的乡村振兴协作社群）验证过的"任务 + 积分 + 荣誉"数字协作机制，并融入 DAO（去中心化自治组织）的共治理念，形成全国高校中具有示范意义的"**数字化志愿服务操作系统**"。

---

## 一、我们要解决什么问题

请看三个真实的校园场景：

1. **找项目像"捡漏"**：想做志愿的同学小李，只能靠刷新各院系公众号和年级群里的招募消息。好多项目他看到时报名已截止，而他擅长的电脑维修却一直没有用武之地。
2. **组织方"招人难、管理累"**：某志愿服务队负责人小王，每次活动要在 5 个群里发招募、手动整理接龙名单、活动当天纸质签到、事后把照片和名单发给老师录入时长——一次活动光"填表"就要花三四个小时。
3. **时长"看不见、等不来"**：大四学生小张申请推免时需要志愿服务证明，翻遍聊天记录凑材料，等学院盖章等了两周。至于三年里做过哪些志愿、帮过多少人，没有任何一份完整的档案。

**一句话概括痛点：项目在群里，报名在接龙，记录在 Excel，证明在等通知。** 这不是一个组织的问题，而是全校志愿服务缺乏一套统一的"操作系统"。

## 二、背景概念：什么是 DAO？什么是乡建DAO？

> 本节为科普，熟悉这些概念的读者可直接跳到第三节。

### 2.1 DAO 是什么

DAO 读作"道"，是英文 **Decentralized Autonomous Organization** 的缩写，中文叫"**去中心化自治组织**"。

名字听着陌生，道理其实很朴素：**一种没有"总经理"的组织方式**——目标和规则提前写清楚、摆在明处；日常工作大家一起干；每一份贡献都有记录、可追溯；大事由成员共同商量决定。

可以把它类比成一个**数字化的学生社团**：章程公开、账目公开、干活留痕、评优看贡献。它最早出现在区块链（一种防篡改的电子记账技术）领域，但我们借鉴的只是**组织协作的理念**——规则公开、贡献留痕、集体决策——**不涉及任何网络货币交易**。

### 2.2 乡建DAO 是什么

乡建DAO 是**温铁军教授团队**在乡村振兴实践中发起的协作社群（"乡建"即乡村建设）。他们把乡村里的大小事务——拍摄纪录片、整理村史、设计农产品包装、给留守儿童上课、运营乡村书吧……以"**任务帖**"的形式公开发布，志愿者自由认领；完成任务获得"**稻米**"积分，积分记录每个人的贡献、可在社区兑换福利；表现突出的个人和团队还会获得**数字荣誉徽章**。

2026 年 9 月，我们在 **ETHShanghai**（以太坊生态的国际性技术会议）现场了解到乡建DAO 的实践，随后系统调研了他们的公开资料（见《01-乡建DAO调研报告》）。他们与福建屏南县政府联合举办的"**数智乡建黑客松**"（编程创新活动）尤其亮眼：**3 天里 133 位参与者为乡村提出了 71 个数字化方案**，赛后多个方案持续落地开发。

**这套实践证明了两件事**：① "任务 + 积分 + 荣誉"的数字协作机制，能够低成本组织起大规模、跨地域的志愿协作；② 一群有热情的年轻人，通过好的机制设计，可以为社会真实地解决问题。

### 2.3 乡建DAO 给 RUCDAO 的启发

我们的校园志愿服务场景与乡建DAO 的乡村建设场景高度相似——都是"**有很多事要做、有很多人愿意帮忙、缺一套撮合与记录的机制**"。借鉴映射如下：

| 乡建DAO 的做法 | RUCDAO 的借鉴 |
|---|---|
| 任务帖悬赏（拍照 500 稻米、剪辑 800 稻米……） | **志愿项目/任务发布**：每个项目明示内容、要求、时长、回报 |
| "稻米"积分记录贡献 | "**米粒**"记录志愿时数（1 小时 = 100 粒） |
| 节点制（各团队分区负责） | **发布节点制**：院系志协、社团、校级组织各自发布与管理项目 |
| 数字荣誉徽章 | **志愿荣誉徽章**（星级志愿者、技能徽章） |
| 数智乡建黑客松"把代码写在大地上" | "**科技走入乡村**"寒暑假实践 + 创新大赛 |
| 社区公约、共同治理 | **《RUCDAO 社区公约》**：规则公开，修订需三分之二通过 |

## 三、RUCDAO 是什么

**一句话定位：人大校内志愿服务的"操作系统"——让找志愿、做志愿、记时数、得回馈，在一个平台上完成。**

平台分**两端**，服务两类用户：

**学生端**（为志愿者设计）
- **项目库**：全校志愿项目一处聚合，按领域（支教/环保/助老/赛会/技能/乡村）筛选，明示时间、地点、名额、时长、米粒数，一键报名；
- **广场**：轻量的"任务帖"（如"活动跟拍 500 粒""海报设计 300 粒"），适合课余时间灵活参与；
- **我的**：一份**终身可查的志愿档案**——服务记录、时数账本、荣誉徽章、证明导出；
- **权益商店**：米粒换面包券、咖啡券、打印券、文创周边、名企参访名额、年度"志愿之星"奖杯。

**发布端**（为志愿服务组织设计）
- **发布台**：填一张表发布项目（岗位、时长、难度系数自动折算米粒），可同步在"志愿北京"建项；
- **项目管理**：报名名单、服务确认（点名式核对），杜绝"挂名志愿"；
- **发放台**：**一次点击完成时数认证**——记录存档、米粒入账、志愿北京批量录入。

### "米粒"是什么：志愿时数的认证方式

"米粒"是这套记账系统的名字（灵感来自乡建DAO 的"稻米"，也呼应人大校徽的麦穗意象——**粒粒皆辛苦，点滴贡献都算数**）。规则非常简单：

> **做 1 小时志愿服务，记 100 粒米粒**；技术型服务（如维修、支教备课）上浮 50%，艰苦偏远地区服务翻倍。

米粒就像超市积分卡的积分：攒多了可以换面包券、周边和机会。但它**不是钱**——不能充值购买、不能转给他人、不能换成现金；它本质上是**你志愿时数的可信电子账本**：2,340 粒 = 23.4 小时，每一笔增减都带着存档编号，永久可查、谁也改不了。

我们把这套机制命名为 **PoV（Proof of Volunteer，志愿服务贡献证明）**：**每一次真实的服务，都会被验证、被记录、成为一份可查证的贡献证明。**

配套设计还包括：志愿服务记录会在**区块链存证**（一种防篡改的电子记账方式，常用于电子合同、版权登记，让记录"刻"在公开账本上、事后无法涂改）；长期贡献者获得不可转让的**数字荣誉徽章**，可写进简历和综测材料。

## 四、这个项目好在哪里：优点与优势

### 4.1 对学生：参与门槛低、付出有回报、成长有档案

| 现状 | 用了 RUCDAO 之后 |
|---|---|
| 刷群捡漏找项目 | 全校项目一处看、按兴趣筛选、一键报名 |
| 时长录入靠人情、要等一学期 | 服务确认后一周内录入志愿北京，档案自动生成 |
| 干多干少一个样 | 米粒按时数入账，兑面包券、周边、参访机会 |
| 零散技能无处发挥 | "任务帖"悬赏：摄影、海报、维修、文案都能贡献 |
| 综测/推免凑证明 | 一份终身可查、可导出的志愿档案，含荣誉徽章 |

### 4.2 对志愿服务组织：招募省力、管理省心、留得住人

- 发布项目 5 分钟，报名/签到/确认/录入全流程线上化，**一次活动的事务性工作从 3—4 小时降到半小时**；
- 报名者实名（学号），服务记录三重确认（负责人 + 互评 + 抽检），**"挂名志愿"无处藏身**；
- 米粒激励和荣誉徽章让志愿者有持续参与的动力，队伍更好带。

### 4.3 对学校：志愿服务数字化、思政工作有抓手、创新成果可展示

- **数据资产**：全校志愿服务的项目库、参与度、时数总账一目了然，为评优、推免、年度报告提供权威数据；
- **育人载体**：契合劳动教育、实践育人、教育数字化方向；"科技走入乡村"活动直接服务乡村振兴国家战略；
- **创新名片**："数字化志愿服务操作系统 + PoV 贡献证明机制"在高校志愿服务领域具有**先发示范意义**，可用于招生宣传、对外交流、教学案例。

### 4.4 项目自身的优势

1. **站在成功实践的肩膀上**：机制设计直接借鉴乡建DAO 已经过大规模真实场景检验的"任务 + 积分 + 荣誉"模式，不是闭门造车；
2. **技术成熟、成本极低**：基于成熟的开源内容管理系统二次开发（详见附录二），年运维成本可控制在**千元以内**，学生团队完全可自主维护；
3. **开源可复制**：整套系统计划开源，**一套系统、多校复用**，兄弟高校部署只需替换校名与配置；
4. **合规稳健**：米粒从机制设计上就与"网络货币"划清界限（不能充值、不能转让、不能换钱），服务时长照实录入志愿北京——**设计上就把政策风险堵死**（详见第八节）；
5. **已有工作基础**：立项前我们已完成乡建DAO 系统调研、可行性与合规分析、可交互产品原型（双端）和开源仓库（见附录三），**不是从零开始**。

## 五、推广前景

### 5.1 校内推广（一年内）

1. **试点期**（2027 春季学期）：2 个院系试点，跑通"发布—参与—记录—回馈"全流程，打磨面包券等首批回馈；
2. **全校期**（2027 秋季学期）：全校开放，纳入迎新季"一分钟注册、两分钟接单"推广，举办首届"**科技走入乡村**"实践 + 创新大赛（对标乡建DAO"数智乡建黑客松"：赛前线上公开课 → 3 天线下共创 → 赛后落地孵化）；
3. **常态化**：每月"志愿 × 技术"共学共创工作坊、学期"PoV 挑战赛"，让平台成为校园志愿文化的大本营。

### 5.2 校际推广（一到两年）

- 系统**开源**后，兄弟高校（尤其北京高校圈）可低成本复制；我们提供部署文档与运营手册；
- 与乡建DAO、LXDAO（国内知名的技术公益社区）建立互学机制：任务联发、活动联办、荣誉互认探索；
- 长期可形成"**高校志愿服务数字化联盟**"，共享项目资源（如联合支教、联合乡村实践）。

### 5.3 社会推广与国家战略对接

- **"科技走入乡村"**：组织同学赴乡建DAO 共建村庄（如福建龙潭村）开展数字支教、村史数字化、AI 助农——直接服务**乡村振兴**国家战略，是极好的社会实践与新闻素材；
- 平台模式可向**社区治理、公益组织**输出：街道养老助残、博物馆志愿、大型赛会服务都是潜在场景；
- "贡献证明"机制可为**社会信用与志愿服务体系建设**提供一个校园样本。

### 5.4 竞赛与学术前景

项目可参加"挑战杯"大学生课外学术科技作品竞赛、中国国际大学生创新大赛（原"互联网+"）、中国大学生计算机设计大赛、首都志愿服务项目大赛等；PoV 贡献证明机制本身具有学术探讨价值，可延伸为课程论文与调研报告。

### 5.5 长期愿景

**让志愿服务像一份"数字档案"一样可信、完整、可积累**——无论评优、升学还是求职，一次导出就能证明你的每一份付出；让"有时间就做志愿"像刷校园卡一样自然，成为人大人的生活方式。

## 八、合规与安全设计

志愿服务项目面向全校同学，安全稳健是第一位的。本项目从**机制设计**上就把常见风险堵死：

1. **米粒不是"网络货币"**：不能用人民币充值购买、不能相互转让、不能兑换现金——它只是一种**志愿服务时数的记账方式**（就像校园卡积分），没有任何金融属性；
2. **时长永远照实记录**：服务时长以真实服务为准，由负责人确认后录入志愿北京，米粒不参与时长的"买卖"；
3. **回馈走"兑换券"**：米粒换的是面包券、周边等实物与机会，商品由商户以人民币标价结算，米粒只在兑换时核销；
4. **实名与防作弊**：学号实名注册，服务记录三重确认，查实造假清零公示；
5. **先立项、后上线**：平台运行以校团委/校志协的立项背书为前提，规则以《RUCDAO 社区公约》公开发布。

详细论证见《02-可行性与合规分析》。

## 九、团队与保障需求

**现有团队**：信息学院志愿服务部（项目发起与运营）+ 校内技术志愿者（开发维护）。

**恳请学校/老师支持的事项**：

1. 校团委 / 校青年志愿者协会**立项背书**，平台以校志协名义对接"志愿北京"组织资质；
2. 指导老师 1 名（思政教育、公共管理或计算机方向均可）；
3. 服务器与校内域名支持（或信息化办云主机资源，年成本可控）；
4. 协助对接后勤、食堂面包房、校内商户作为回馈券源；
5. （可选，长期）将平台服务记录纳入劳动教育 / 社会实践学分认定体系。

## 十、风险与对策

| 风险 | 对策 |
|---|---|
| 上线初期参与度不足 | 先把志愿服务部存量 20+ 项目搬上平台；"任务帖"悬赏 + 面包券引流；迎新季集中推广 |
| 服务记录可信度 | 负责人确认 + 同伴互评 + 平台抽检三重机制，造假清零公示 |

| 名词 | 一句话解释 |
|---|---|
| **DAO（去中心化自治组织）** | 没有"总经理"的组织：规则公开、贡献留痕、大事共决，像一个数字化的社团 |
| **乡建DAO** | 温铁军教授团队发起的乡村振兴协作社群，用"任务帖 + 稻米积分 + 数字徽章"组织志愿者 |
| **米粒（RUCOIN）** | 我们的志愿时数记账方式：1 小时 = 100 粒，可兑面包券等回馈，不是钱、不能转让 |
| **PoV（志愿服务贡献证明）** | 本项目的核心机制：每一次真实服务都被验证、被记录、永久可查 |
| **链上存证（区块链存证）** | 把记录"刻"在公开透明、无法涂改的电子账本上，常用于电子合同、版权登记 |
| **数字荣誉徽章** | 授予长期贡献者的电子荣誉证书，不可转让、永久保存，可写进简历 |
| **任务帖** | 借自乡建DAO 的轻量招募形式：一件具体的活儿，明示内容、要求与报酬，志愿者自由认领 |
| **黑客松（编程创新活动）** | 短时间的集中共创活动，不同专长的人组队，为真实问题现场设计并做出方案 |
| **节点** | 平台中的发布与管理单元（如各院系志协、社团），对应乡建DAO 的"节点制" |

## 附录二：技术方案要点（简要）

- **平台主体**：基于成熟开源内容管理系统（WordPress）二次开发——成本低、安全性久经考验、非技术同学也能管理内容；
- **记录与凭证**：自研插件管理项目、报名、服务记录与米粒账本；配套的"贡献凭证"智能合约已开发完成并通过编译测试（`contracts/RuCoin.sol`）；
- **对接志愿北京**：开发适配器，实现建项同步与服务时长批量录入；
- **产品设计**：采用苹果设计规范（清晰、简洁、支持深浅色模式），已完成可交互原型；
- **保障**：整套系统开源托管于 GitHub，配套自动验证脚本（`verify.ps1`），交接与复用无障碍。
