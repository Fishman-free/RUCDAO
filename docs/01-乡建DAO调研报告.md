## 0. TL;DR

- **乡建DAO** 是温铁军团队（国仁乡建）发起的"乡建 3.0"实验：用 DAO 框架 + 开源数字工具构建"社会软件"，召集人为严晓辉（香港岭南大学研究员）。
- **写作形式**：社区公约（章程条款体）、任务帖（【任务】+ 内容/要求/奖励）、活动招募帖（岗位清单 + 稻米酬劳、"多劳多得"）、共学共创直播预告，公众号首发 + 搜狐转载，B 站/视频号做活动预热。
- **激励（稻米）**：社区积分，按任务/工作量发放或打赏（单件 200—1000 稻米量级），定位是"贡献记录 + 社区内消费/打赏"，姊妹社区南塘DAO 的"南塘豆"进一步赋予投票权；荣誉徽章规划为链上不可转让的 SBT。
- **技术栈**：社交层 = **自部署/定制的 Bluesky（AT Protocol）**（实测 xjdao.xyz 的 HTML 为 bskyweb 应用壳）；链上层 = 以太坊生态（南塘豆为 OP 链 ERC-20，徽章规划 SBT）；协作层 = Notion、Fairsharing 工时记录、投票平台、微信生态。
- **黑客松**：首届"数智乡建黑客松"（2026-05，福建屏南熙岭乡），3 天 133 人产出 71 个乡村方案，软件/硬件/文创三赛道，赛后成果（如龙潭村"数字村民通证"）持续落地——"把实验室搬进麦田，把代码写在大地"。

## 2. 平台形态与写作形式（xjdao.xyz / xjdao.net 实测）

### 2.1 平台形态

xjdao.xyz（镜像域名 xjdao.net）是一个**社区信息流平台**：

- 首页即"**广场**"（信息流），按时间线展示各节点/个人的帖子；
- 个人中心以节点为单位组织（如 `/profile/国仁乡建传媒`、`/profile/重庆乡建团队`），既是主页也是任务发布台；
- 支持**话题标签**聚合（如 `#活动` `#任务`）；
- 每个账号的 handle 形如 `nanxin.web5.xjdao.xyz`（域名型身份标识）。

### 2.2 写作形式（四类典型文体）

1. **社区公约（章程条款体）**：分条列款（节点、稻米、徽章、投票、生效与修订），是整个社区的"宪法"。
2. **任务帖（悬赏体）**：`【任务】+ 主题`，正文固定为 **内容 / 要求 / 投稿方式 / 奖励**。例：
   > 【任务】我"印象最深的一个村庄"征集启事 —— 内容：为记录乡村变迁风貌，留存乡土动人记忆……要求：……
3. **活动招募帖（岗位清单体）**：逐岗位列人数与酬劳，明确"**多劳多得**"。例（某活动招募）：
   > 1. 视频拍摄 1 人——负责全程活动记录，酬劳 500 稻米；
   > 2. 视频剪辑 1 人——制作 1—2 分钟活动短片，打赏 500—1000 稻米不等；
   > 3. 精彩照片征集——限 4 张，每张打赏 200 稻米；
   > 4. 现场分享——在乡建DAO发布活动照片或笔记可获打赏。
4. **长期任务帖（工作量计酬体）**：如"国仁乡建传媒"长期招募志愿者协助学者视频剪辑、录音整理、字幕校对、素材收集、AI 配音，"**根据工作量给予一定的乡建DAO稻米积分奖励**"。

**传播矩阵**：微信公众号首发 → 搜狐等平台转载长文（《乡建DAO社区指南》《玩转乡建DAO》）→ B 站/视频号直播预热（"共学共创"线上系列）→ 平台内广场/标签沉淀。

## 3. 激励发放形式：稻米

- **性质**："乡建DAO稻米积分"——社区贡献积分，不是可交易的投机币。
- **发放途径**：
  1. 任务赏金：完成悬赏任务按件计酬（200—1000 稻米/件量级）；
  2. 活动酬劳：按岗位一次性发放（拍摄 500、剪辑 500—1000……）；
  3. 工作量计酬：长期性工作（剪辑/校对/配音）按工作量核定；
  4. 打赏：社区成员/组织对优质内容的自愿打赏。
- **用途**：社区内打赏、参与活动、支付社区活动费用（社区内循环）。
- **对照——南塘DAO"南塘豆"**（更完整的双代币参考）：
  - 采用**工时制**记录贡献：成员在 **Fairsharing 平台**自主记录工作时长，工时有效性靠社区互评，争议时投票裁定；
  - 现行标准：**1 工时 = 60 元人民币等值的 ETH + 60 南塘豆**（现金部分来自社区捐赠，如投资人刘兵自 2017 年起捐 ETH 资助）；
  - 南塘豆 = **贡献记录 + 投票权凭证**双重功能，持豆越多投票权重越大；南塘豆为 **OP 链上 ERC-20** 代币。
- **荣誉徽章**（《公约》第 20 条）：社区发行**不可转让的数字徽章（SBT）**，表彰人才培育、文化教育、产业发展、社区营造等领域的贡献；由节点推荐、社区核准后颁发，链上永久保存。

## 4. 技术栈（实测结论）

| 层 | 技术 | 证据 |
|---|---|---|
| 社交/社区层 | **Bluesky 社交应用（AT Protocol）自部署/定制** | 实测 xjdao.xyz HTML：`<meta name="generator" content="bskyweb">`、`application-name: Bluesky`、bsky.app 的 og/meta 与 InterVariable 字体、CRA 构建产物 `/static/js/main.*.js`；账号 handle 为 ATProto 域名型（`xxx.web5.xjdao.xyz`） |
| 链上层 | 以太坊生态 | 南塘豆为 **OP 链 ERC-20**（来源：ethpanda《Web3 实习生手册》）；徽章规划 SBT（链上存储的不可转让徽章） |
| 贡献/工时记录 | Fairsharing 平台（自主记录 + 互评验证） | 南塘DAO 记事（中篇） |
| 协作与治理 | Notion（组织主页）、投票平台（提案表决）、微信生态（公众号/视频号/B 站） | 南塘DAO 记事、社区指南 |
| 黑客松成果示例 | 龙潭村"数字村民通证" | 厦门网报道 |

**关键洞察**：乡建DAO 的"web3 底层"其实是**两层**——社交身份/内容层用 AT Protocol（去中心化社交），价值/凭证层才用区块链（ERC-20 积分、SBT 徽章）。稻米积分本身更接近应用内积分账本，链上部分重在"贡献存证与荣誉身份"。

## 5. 黑客松与活动形式

- **首届数智乡建黑客松**（2026-05，福建屏南县熙岭乡，龙潭村等）：
  - 主办：熙岭乡政府 × 国仁乡建 × 乡建DAO × 屏南乡村振兴研究院；
  - 口号："将实验室搬进麦田，把代码写在大地——对物理世界编程，以创意文化展现乡村之美"；
  - 赛道：**软件 / 硬件 / 文创** 三赛道，覆盖智慧村务、AI 乡村服务、农用智能设备、"非遗"数字化；
  - 规模与产出：**3 天、133 名"村民"、71 个乡村方案**；
  - 赛前："共学共创"线上预热系列（B 站/视频号直播，如"不懂代码，也能走向编程自由"）；
  - 赛后：成果持续落地（龙潭村"数字村民通证"定制开发）。
- **田野结合**：Punpun 农场深度参访日等活动，把参访、工作坊（早 9 晚 9 的高强度工作坊）与共创结合。
- **黑客松联动**：南塘DAO"远航计划"组织成员报名参与 ETHShanghai 黑客松，把黑客松作为成员成长通道。

## 6. 对 RUCDAO 的五点启示

1. **积分定位要"贡献记录优先"**：稻米的核心是记录与荣誉，不是金融产品——RUCOIN 必须继承这一点（详见可行性与合规分析）。
2. **任务帖文体可直接移植**：【任务】+ 内容/要求/奖励 的悬赏体非常适合学生志愿场景（摄影、文案、开发、物料等零散志愿任务）。
3. **计量方式要吸取南塘DAO 工时制的后续教训**：《南塘DAO 记事（中篇）》（PANews，2025）显示，"自主记录 + 社区互评"在实际运行中介入失效、争议频发，社区已转向"项目制 + 按成果评估"。对应到校园场景，宜采用"项目组职位定价 + 负责人确认 + 志愿北京录入"（修订详见《03-RUCDAO项目计划书》第二、七部分）。
4. **SBT 徽章低成本高感知**：星级志愿者、技能徽章做成不可转让徽章，评优、综测、简历均可引用。
5. **黑客松要"写在大地上"**：RUCDAO 的"科技走入乡村"黑客松可直接对标数智乡建黑客松的三赛道 + 线上预热 + 赛后落地模式，并可与乡建DAO/龙潭村联办。
